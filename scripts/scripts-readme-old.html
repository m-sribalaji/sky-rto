SKY-RTO

Installation Guide

Install Python3 before running the setup script. All required dependencies and libraries will be installed automatically.
Important
Do not delete, rename, or modify any files before or after installation. The setup requires all bundled files to remain in their original structure.

macOS

Step 1
Open Terminal and navigate to the scripts directory 
cd sky-rto/scripts
Step 2
Make the installer executable 
chmod +x install_macos.sh
Step 3
Run the installer 
RTO_SERVER_URL="http://10.131.80.141:8989" bash install_macos.sh

Windows

Step 1
Open PowerShell and navigate to the scripts directory 
cd sky-rto/scripts
Step 2
Run the installer 
powershell -ExecutionPolicy Bypass -File .\install_win.ps1 -ServerUrl "http://10.131.80.141:8989"
Notes
Ensure Python3 is installed and available in PATH
Use PowerShell on Windows instead of Command Prompt
Verify that the server URL is reachable from your machine
Ensure port 8989 is accessible through firewall/network rules
