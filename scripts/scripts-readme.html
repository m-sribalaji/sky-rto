SKY-RTO

Installation Guide

Download the installer for your platform and run it once. Fully automatic from there.

macOS Apple Silicon

Step 1
Download the Mac installer
rto-mac-arm64
Step 2
Open Terminal in the download folder and run 
xattr -d com.apple.quarantine rto-mac-arm64 && chmod +x rto-mac-arm64 && ./rto-mac-arm64
Step 3
Browser opens automatically for registration
Fill in your name and employee ID, then click Register. That's it — the agent installs itself and runs silently from here on.

Windows x64

Step 1
Download the Windows installer
rto-win.exe
Step 2
Double-click rto-win.exe
If Windows SmartScreen appears, click More info → Run anyway. This is normal for internally distributed tools not signed with a paid certificate.
Step 3
Browser opens automatically for registration
Fill in your name and employee ID, then click Register. The agent registers itself to auto-start on every login.

Command Reference — for power users and troubleshooting

The binary accepts flags for manual control. Open Terminal (Mac) or Command Prompt / PowerShell (Windows) in the folder containing the binary.

Command macOS example Windows example What it does
--force ./rto-mac-arm64 --force rto-win.exe --force Force a fresh check-in right now, bypassing the dedup cache. Use when your status looks wrong.
--reset ./rto-mac-arm64 --reset rto-win.exe --reset Clear ALL local caches (config state, lock file, missed-day tracker) then immediately run a fresh check-in. Use after reinstalling or if something is stuck.
--retry ./rto-mac-arm64 --retry rto-win.exe --retry Manually retry all check-ins that were queued offline (e.g. when VPN was off). Normally happens automatically — use this to force it now.
--install ./rto-mac-arm64 --install rto-win.exe --install Reinstall the auto-start entry (launchd on Mac, registry Run key on Windows). Use if auto-start stopped working after an OS update.
--uninstall ./rto-mac-arm64 --uninstall rto-win.exe --uninstall Remove auto-start entries. The binary itself is not deleted — just the startup registration.
Notes
Sky VPN required. Connect to Sky VPN before running the installer if you are at home. The agent will queue your check-in locally and sync automatically once VPN is connected.
Windows SmartScreen. If a blue warning appears, click More info → Run anyway. This is expected for internally distributed tools.
Something not working? Run the binary with --reset to clear all caches and start fresh. Share ~/.rto_tracker/checkin.log with your admin if the issue persists.
